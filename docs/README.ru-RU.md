NocoITAM — система управления IT-активами с открытым исходным кодом, построенная на [NocoBase 3](https://www.nocobase.com). Традиционные системы ITAM — это реестры, которые ведут вручную. В NocoITAM агенты разбирают расхождения с MDM, собирают комплекты для новых сотрудников и перед каждой закупкой проверяют склад и неиспользуемые активы. Каждое устройство, каждое место и каждый расход на учёте.

## Что она умеет

- **Перед каждой закупкой — сначала склад.** Когда заказ уходит на согласование, помощник по согласованию проверяет, хватит ли склада или неиспользуемых устройств, сравнивает прошлые цены и похожие заявки и готовит решение и комментарий для согласующего.
- **Новички готовы к первому дню, уходящие возвращают всё.** Комплект нового сотрудника сразу сверяется со складом и свободными местами, а недостающие заказы создаются в один клик. Устройства, аксессуары и места уходящего сотрудника отслеживаются, пока всё не вернётся, а его записи передаются другим.
- **Расхождения с MDM превращаются в план.** После каждой синхронизации с Intune или Jamf Pro агент разбирает несовпадения: другой пользователь — ответственному за устройство, незарегистрированное устройство — администраторам активов, неясные случаи — человеку.
- **Один реестр для всего, что есть у IT.** Устройства, аксессуары, расходные материалы, компоненты и права на ПО — от закупки, приёмки, выдачи и временного пользования до ремонта, инвентаризации и списания, у каждой записи своя история.
- **Помощник на каждой странице.** Хранитель активов отвечает по записям, которые вам доступны, и предлагает планы, которые вы подтверждаете. Когда к задаче прилагается коммерческое предложение, счёт или накладная, ИИ читает документ и заполняет форму, а вы её проверяете. Агенты предлагают, решают люди.
- **Ваши правила, ваш код.** Опишите стандартные комплекты, бюджеты и правила согласования в бизнес-руководстве, и каждый агент будет им следовать. Попросите агента для программирования изменить исходный код ITAM. Открытый код, собственный хостинг, всё ваше.

## Быстрый старт

### 1. Установка

**С помощью агента для программирования.** Самый простой способ. Откройте Claude Code, Codex или Cursor в папке, где будет NocoITAM, и дайте ему такое задание:

```text
Установи NocoITAM из https://github.com/nocobase/NocoITAM и запусти его, следуя AGENTS.md и README репозитория.
```

**Вручную.** Нужны Node.js 24 или новее и pnpm 10 (`corepack enable`). По умолчанию данные хранятся в файле SQLite; PostgreSQL и MySQL тоже поддерживаются.

```bash
git clone https://github.com/nocobase/NocoITAM.git
cd NocoITAM
pnpm install
pnpm nocobase config init --dialect sqlite
pnpm dev
```

### 2. Вход

Откройте адрес `Local:`, который выводит `pnpm dev`, обычно `http://127.0.0.1:13000/main/`, и войдите как `nocobase` с паролем `admin123`.

### 3. Импорт демо-данных

Их предлагает баннер вверху, или откройте **Настройки → Демо-данные**. Они добавляют компанию примерно из сорока человек с её устройствами, складом и лицензиями, заказами, ремонтами, инвентаризациями и списаниями, а также демо-платформы Intune и Jamf; удалите их там же, когда начнёте работать всерьёз.

### 4. Настройка модели ИИ

Добавьте сервис моделей с ключом в разделе **Команда агентов → Модели**, например DeepSeek, OpenAI, Claude, Gemini или Qwen. Он нужен Хранителю активов и агентам; всё остальное работает без него.

В [руководстве](guide.md) (на английском) описаны дальнейшие шаги, демо-учётные записи, роли, агенты, настройка (ИИ, MDM, базы данных), развёртывание и разработка.
